# v0.3.0

> At the core of this release: **prediction-pipeline outage root-cause fix** (the 38-questions-skipped alarm that persisted for 4 days) plus a **full Ponytail code trim** (net −750 lines, zero new dependencies, zero behavior change).

[中文版 →](v0.3.0.md)

---

## Prediction pipeline fixes

- **Skipped predictions root-caused**: DeepSeek's Responses API rejects `json_format` requests with HTTP 400 unless the `input` contains the word "json" — both `websearch_predictor` and `llm_resolver` now include a JSON output example in their input template, ending the 38-question skip cascade
- **Async entrypoint defaults**: `aresponses_create` gained defaults for `max_output_tokens`/`temperature`/`json_format`/`timeout`, eliminating the missing-argument `TypeError` that voided every sample
- **Backfill**: all 17 never-predicted questions plus expired 7-day update windows re-predicted (`predicted=17, skipped=0`)

## Code trim (Ponytail, 4 parallel agents)

- `ops/health.py` 275→99: `_c` dict helper, `_union_predict` inlined, probe checks looped, scoreboard table-driven
- `scripts/evolve.py` 340→171: dropped arm-B experiment block (candidate always None), `_build_base_rates` (1 of 5 keys ever hit), `difficulty_tiers` stats, weekly-review placeholder 40L→10L
- `scripts/daily.py` 250→169: duplicate import removed, `_within_update_window` inlined, dead `sources` param dropped
- `data/storage.py` 1019→936: `canonical_model_name` family deleted (single model can never reach the ensemble branch), `source_*`/`ops_*` rewritten as SQL `json_extract` (N+1 → 1 query)
- `selection/families.py` 229→202: 8 hard-coded family specs extracted into a `FAMILIES` table
- `websearch_predictor.py` 342→234: text/citation extraction merged with `dict.fromkeys` dedup, heartbeat inlined, third `_log_skip` copy deleted
- `pipeline.py` 152→96: single-model weighting removed (always equal weights), `extremize` arg inlined
- `llm/client.py` 232→222: duplicated retry loops extracted into `_post_with_retry`, `_has_answer` hoisted to module level, output-token ceiling unified at 65536
- `web/server.py` 281→248: alert banner inline style → CSS class, `deque`/`Query`/`with_suffix`/`HTTPException` replace hand-rolled code
- `ops/probes.py` 149→141: `csv.DictReader` replaces manual CSV splitting

## Stability

- `crawl_social.py`: 1s tolerance on the mtime freshness comparison — fixes a Windows timestamp-precision test flake (real crawls take >30s, unaffected)
- Alert ack cleanup: 10 stale unacknowledged alert files settled, dashboard banner cleared
