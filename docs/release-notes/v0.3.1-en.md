## One-command install

```bash
npm i -g foresight-agent
foresight "Will the Fed cut rates in September?" --closes 2026-09-17
```

- **Prebuilt self-contained binaries** (Python runtime + duckdb bundled inside): Windows x64, macOS x64, macOS arm64, Linux x64 — downloaded per platform at install time
- **No Python, no uv** — the CLI runs from any directory
- Esbuild-style distribution: the main package ships a cross-platform launcher, per-platform packages are pulled via optionalDependencies
- PyInstaller entry at `packaging/entry.py`; CI matrix (`.github/workflows/publish-npm.yml`) builds and publishes all platforms automatically on `v*` tags
- `[project.scripts]` `foresight` CLI entry added to `pyproject.toml`

## Install

- `npm i -g foresight-agent` = one line, same experience as any modern CLI tool
- README quick-start section now documents this as the zero-configuration path
