# v0.3.1

> 本版核心：**npm 一键安装分发** —— `foresight-agent` 现在可以通过 npm 一条命令安装使用，用户机器上无需 Python、无需 uv。

**[English →](https://github.com/Finn763/foresight/blob/v0.3.1/docs/release-notes/v0.3.1-en.md)**

---

## 一键安装

```bash
npm i -g foresight-agent
foresight "Will the Fed cut rates in September?" --closes 2026-09-17
```

- **预编译单文件二进制**（内含 Python 运行时 + duckdb）：Windows x64 / macOS x64 / macOS arm64 / Linux x64，安装时按平台自动拉取
- **免 Python、免 uv** —— 任意目录直接运行
- esbuild 式分发：主包带跨平台启动器，平台子包经 optionalDependencies 按需安装
- PyInstaller 打包入口 `packaging/entry.py`；CI 矩阵（`.github/workflows/publish-npm.yml`）在 `v*` tag 时自动构建并发布全部平台
- `pyproject.toml` 增加 `[project.scripts]` `foresight` CLI 入口

## 安装

- `npm i -g foresight-agent` 一行安装，与主流 CLI 工具同等体验
- README Quick start 已将此列为零配置路径
